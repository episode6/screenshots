# screenshots
A place to store screenshots for prs.

All images and videos are stored in [Git LFS](https://git-lfs.com)
(see `.gitattributes`). Embed files with
`https://media.githubusercontent.com/media/episode6/screenshots/main/<path>`
— `raw.githubusercontent.com` URLs only return the LFS pointer text.
Don't upload media through the GitHub contents API (it bypasses LFS);
use the `publish-screenshots` agent skill's `upload.sh` instead.
